# 🌍 Geo Steam - Анализ геолокации

Веб-приложение для отслеживания и анализа геолокации пользователя в стиле Steam. Приложение позволяет отслеживать местоположение пользователя, собирать статистику по странам и городам, а также визуализировать данные о путешествиях.

## ✨ Основные возможности

- **Отслеживание геолокации** - автоматическое определение местоположения пользователя
- **Статистика по странам** - анализ времени пребывания в разных странах
- **Статистика по городам** - детальная информация о посещенных городах
- **История местоположений** - полная история всех записей геолокации
- **Визуализация данных** - графики и диаграммы для анализа статистики
- **Современный UI** - интерфейс в стиле Steam с темной темой
- **Адаптивный дизайн** - поддержка мобильных устройств

## 🛠 Технологии

### Backend
- **Node.js** - серверная платформа
- **Express.js** - веб-фреймворк
- **SQLite** - база данных
- **CORS** - поддержка кросс-доменных запросов
- **Helmet** - безопасность

### Frontend
- **React 18** - пользовательский интерфейс
- **TypeScript** - типизация
- **Styled Components** - стилизация
- **React Router** - навигация
- **Recharts** - графики и диаграммы
- **Axios** - HTTP клиент

## 📦 Установка и запуск

### Предварительные требования
- Node.js (версия 16 или выше)
- npm или yarn
- Docker (опционально, для Лаб. 7)

### Лабораторные работы

Проект адаптирован под 7 лабораторных работ. Подробная документация: [labs/README.md](labs/README.md)

| Лаба | Тема | URL |
|------|------|-----|
| 1 | HTML + CSS | http://localhost:5000/labs/static/index.html |
| 2 | Формы и валидация | http://localhost:5000/labs/static/auth.html |
| 3 | REST + Telegram | http://localhost:3000/feedback |
| 4 | MVC (Express) | http://localhost:5000/mvc |
| 5 | База данных | API `/api/auth/register` |
| 6 | Real-time JSON | http://localhost:3000/comments |
| 7 | Docker | `docker-compose up --build` |

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd geo-steam
```

### 2. Установка зависимостей
```bash
# Установка всех зависимостей (сервер + клиент)
npm run install-all

# Или установка по отдельности:
npm install
cd server && npm install
cd ../client && npm install
```

### 3. Запуск приложения

#### Режим разработки (рекомендуется)
```bash
# Запуск сервера и клиента одновременно
npm run dev
```

#### Запуск по отдельности
```bash
# Запуск сервера
npm run server

# В новом терминале - запуск клиента
npm run client
```

### 4. Открытие приложения
После запуска приложение будет доступно по адресам:
- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:5000

## 🚀 Использование

### Первый запуск
1. Откройте приложение в браузере
2. Разрешите доступ к геолокации при запросе браузера
3. Нажмите "Начать отслеживание" на главной странице
4. Изучите статистику в разделе "Статистика"

### Основные разделы

#### 📊 Дашборд
- Текущее местоположение
- Краткая статистика

#### 📈 Статистика
- Графики по странам и городам
- Детальная статистика посещений
- Время пребывания в каждом месте

#### 📜 История
- Полная история местоположений

#### ⚙️ Настройки
- Настройки отслеживания

- Управление данными

## 🔧 API Endpoints

### Геолокация
- `POST /api/location/update` - обновление местоположения
- `GET /api/location/history/:userId` - история местоположений

### Статистика
- `GET /api/stats/countries/:userId` - статистика по странам
- `GET /api/stats/cities/:userId` - статистика по городам

### Система
- `GET /api/health` - проверка состояния сервера

## 🐛 Устранение неполадок

### Проблемы с геолокацией
1. Убедитесь, что браузер поддерживает геолокацию
2. Разрешите доступ к местоположению в настройках браузера
3. Проверьте, что устройство имеет GPS или доступ к интернету

### Проблемы с сервером
1. Убедитесь, что порт 5000 свободен
2. Проверьте, что все зависимости установлены
3. Проверьте логи сервера на наличие ошибок

### Проблемы с клиентом
1. Убедитесь, что порт 3000 свободен
2. Проверьте консоль браузера на наличие ошибок
3. Попробуйте очистить кэш браузера
