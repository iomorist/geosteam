Миссия

Создать удобный инструмент для анализа географических перемещений пользователя с наглядной визуализацией данных.

Технологический стек

  1. Backend — Express.js, SQLite, bcrypt
  2. Frontend — React 18, TypeScript
  3. DevOps — Docker, микросервисы
  • REST API в формате JSON
  • WebSocket для real-time обновлений
  • Telegram Bot API для уведомлений

Лабораторные работы

Курс веб-разработки — от HTML/CSS до Docker.

2. Формы и валидация → auth.html

3. REST API + Telegram → feedback.html

4–7. MVC, БД, Real-time, Docker → React-приложение
